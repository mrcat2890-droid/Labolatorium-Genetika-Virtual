
## Changelog Policy
Selalu catat dan dokumentasikan setiap perubahan fitur, revisi bug, atau refaktorisasi kode yang disetujui ke dalam file `CHANGELOG.md` secara proaktif sebelum mengakhiri tugas, tanpa perlu menunggu perintah dari pengguna.

## Code Policy
1. Kalau buat code simulasi genetika, usahakan carikan literatur pendukungnya agar simulasi sesuai dengan data ilmiah.
2. Jangan buat file baru kalau tidak diperlukan, lebih baik modifikasi file yang sudah ada.
3. Buatkan code yang bersih, mudah dibaca, dan mengikuti best practice dalam penulisan kode.
4. Jangan ada simulasi yang tidak sesuai dengan literatur dan melenceng dari materi genetika.
5. berikan terlebih dahulu tutorial di dalam setiap simulasi agar mudah dipahami oleh pengguna. 
6. setiap tata letak dan layout di dalam simulasi harus tertata rapi dan minim AI sloppy seperti AI yang tidak rapi dalam peletakan button atau komponen lainnya.
7. berikan tambilan simulasi yang tidak terlalu kaku dan buatlah animasi yang interaktif.
8. periksa kembali code yang telah di buat apakah sudah sesuai dengan materi genetika yang ingin disampaikan dan bisa kamu push ke lokal.
